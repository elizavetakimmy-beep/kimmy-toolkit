# kimmy-toolkit

Набор скиллов для Claude Code от Елизаветы Ким (@elizaveta_kimmy).

## Что внутри

**Аудитория и продукт** (авторы скиллов — Илья, блог fillikam):
- `audience-segments-meanings` — разбор ЦА на сегменты по лестнице Ханта, мысли и возражения каждого сегмента, смыслы под каждый уровень. Скажи: «разбери сегменты моей аудитории».
- `audience-critique-roleplay` — три раздражённые персоны из твоей ЦА разносят твой продукт и подачу. Скажи: «раскритикуй мой продукт как моя аудитория».
- `product-matrix-build` — продуктовая линейка от лидмагнита через трипваер к основному продукту. Скажи: «собери продуктовую матрицу».
- `product-launch-plan` — план запуска онлайн-продукта с нуля, с датами и метриками. Скажи: «распиши план запуска».
- `blind-spots` — психоаналитический разбор слепых зон с картой паттернов. Скажи: «разбери мои слепые зоны».

**Инструменты**:
- `data-dashboard-from-file` — красивый интерактивный дашборд из любой таблицы (Excel, CSV). Скажи: «сделай дашборд из этого файла».
- `prompt-master` — генератор оптимизированных промптов под любые нейросети. Скажи: «напиши промпт для…».
- `reels-skill-builder` — собирает твой личный навык написания сценариев Reels: ты даёшь 5–7 своих сценариев, Claude разбирает стиль, согласовывает его с тобой на тестовом сценарии и создаёт отдельный навык под твой проект. Скажи: «сделай мне навык для сценариев рилс». Для каждого проекта (свой блог, клиенты) — свой навык.

## Установка

В Claude Code выполни две команды:

```
/plugin marketplace add <ссылка на GitHub-репозиторий>
/plugin install kimmy-toolkit@kimmy
```

После установки скиллы подхватываются сами — просто пиши запросы обычными словами, как в примерах выше.
