# kimmy-toolkit

Набор скиллов от Елизаветы Ким (@elizaveta_kimmy) для экспертов, которые ведут блог и продают свои продукты. Работают и в обычном Claude — на сайте и в приложении, — и в Claude Code.

## Что внутри

**Аудитория и продукт:**
- `segmenty-i-smysly` — разбор твоей аудитории на сегменты по уровням осознанности: мысли, сомнения и возражения каждого сегмента и смыслы, которые ему транслировать. Итог — карта аудитории, по которой пишется контент. Скажи: «разбери мою ЦА».
- `kritika-ot-auditorii` — фокус-группа из персон твоей аудитории разбирает твой оффер, лендинг или продукт и вытаскивает реальные причины отказа. Итог — список правок с приоритетами. Скажи: «покритикуй мой оффер глазами клиента».
- `produktovaya-matritsa` — линейка продуктов от лид-магнита через трипвайер к основному: обещание каждой ступени, логика переходов, гипотезы цен. Скажи: «выстрой мою продуктовую линейку».
- `plan-zapuska` — план запуска продукта с нуля: активы, модель запуска, календарь с датами, воронка с цифрами, метрики. Скажи: «помоги спланировать запуск».

**Инструменты:**
- `data-dashboard-from-file` — красивый интерактивный дашборд из любой таблицы (Excel, CSV). Скажи: «сделай дашборд из этого файла».
- `prompt-master` — генератор оптимизированных промптов под любые нейросети (автор — Nidhin Joseph Nelson, лицензия MIT). Скажи: «напиши промпт для…».
- `reels-skill-builder` — собирает твой личный навык написания сценариев Reels: разбирает твой материал, фиксирует правила формата, согласовывает их с тобой на тестовом сценарии и создаёт отдельный навык под твой проект. Работает и когда своих сценариев ещё нет — тогда собирает из твоей темы, твоих текстов и того, что тебе нравится у других. Скажи: «сделай мне навык для сценариев рилс». Для каждого проекта (свой блог, клиенты) — свой навык.
- `karusel-skill-builder` — то же самое для каруселей: фиксирует, как режется текст по слайдам и как слайды выглядят (цвета, шрифт, поля), проверяет на одной карусели и отдаёт готовый навык. Скажи: «собери мне скилл для каруселей».

## Установка

**В обычном Claude (сайт или приложение):** скачай архив нужного скилла из папки [zips](zips/), распакуй и загрузи папку в настройках Claude (Настройки → Возможности → Навыки). Можно ставить по одному, только те, что нужны.

**В Claude Code** — весь набор двумя командами:

```
/plugin marketplace add elizavetakimmy-beep/kimmy-toolkit
/plugin install kimmy-toolkit@kimmy
```

После установки скиллы подхватываются сами — просто пиши запросы обычными словами, как в примерах выше.

## На чём построены скиллы

Скиллы про аудиторию и продукт опираются на классические фреймворки (лестница осознанности Ханта, уровни Шварца, custdev-интервью, формула обещания CABD) и методологию проектирования образовательных продуктов. Каждый скилл доводит до конкретного файла-артефакта, честно разделяет факты и гипотезы и не подменяет живые разговоры с аудиторией.
